# Lung Cancer Classification with Pre-trained CNN Models

## Overview
This project aims to classify lung images into three categories: ACA lung cancer, SCC lung cancer, and Normal. 
The models tested include VGG19, MobileNet, ResNet, EfficientNet, and Inception.

## Project Structure
- `data/`: Contains the training, validation, and test datasets.
- `models/`: Stores trained model weights.
- `results/`: Includes classification reports, confusion matrices, and metrics summaries.
- `notebooks/`: Jupyter notebook for data exploration and preprocessing.
- `src/`: Python scripts for training, evaluating, and utility functions.
